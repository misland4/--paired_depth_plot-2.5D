# Example datasets

## Author-supplied paired example

`research_pairs.xlsx` is an unmodified copy of the supplied `Simulated dataset to demo the code(1).xlsx`. Its original worksheet name `Simulated dataset` remains unchanged. The historical repository filename does not establish data provenance; real versus simulated status for this nine-pair example remains to be clarified.

Column B contains control Lesion scores and column C the corresponding experiment scores. Row 1 contains headers; rows 2–10 contain nine within-subject pairs. Lesion score is dimensionless and ordinal. Sequential display IDs preserve scores and pair order without establishing nine distinct subjects. This workbook generates the main README preview. The workbook and exported figures use [CC BY 4.0](../LICENSES.md).

## Original script example

`paired_values.csv` reproduces the ten pairs embedded in the original supplied script. It is separate from the nine-pair workbook. The original CSV and built-in arrays are preserved for compatibility and are distributed as software examples under Apache-2.0.
