# Example datasets

## Supplied research data

`research_pairs.xlsx` is an unmodified copy of the supplied `Simulated dataset to demo the code(1).xlsx`. The dataset provider confirmed that its nine pairs are real research observations. Its original worksheet name, `Simulated dataset`, remains unchanged.

Column B contains control observations and column C contains the corresponding experiment observations. Row 1 contains headers; rows 2–10 contain nine complete pairs. The script assigns sequential display IDs without changing scores or pair order. This workbook generates the main README preview.

Source SHA-256: `5aff67627188d3528e64b775abea7a2310dae2312189e4f5dce88d7e9a1717d6`.

## Original script example

`paired_values.csv` reproduces the ten pairs embedded in the original supplied script. It is separate from the new research workbook. The original CSV and built-in arrays are preserved for compatibility.
