# Example datasets

## Author-supplied simulated paired example

`research_pairs.xlsx` is a copy of the supplied `Simulated dataset to demo the code(1).xlsx`. Its original worksheet name `Simulated dataset` remains unchanged. The project contact confirms that the nine pairs are **simulated demonstration data**. The historical repository filename does not imply measured research observations.

Column B contains control Lesion scores and column C the corresponding experiment scores. Row 1 contains headers; rows 2–10 contain nine simulated within-subject pairs. Lesion score is dimensionless and ordinal. Sequential display IDs preserve scores and pair order without establishing nine distinct subjects. This workbook generates the main README preview. `paired_values.csv` reproduces the ten pairs embedded in the original supplied script. It is separate from the nine-pair workbook. The original CSV and built-in arrays are preserved for compatibility and are distributed as software examples under Apache-2.0.
